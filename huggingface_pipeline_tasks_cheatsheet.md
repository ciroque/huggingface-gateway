# 🤖 Hugging Face Pipeline Tasks Cheat Sheet

A concise reference to common `pipeline` tasks in the Hugging Face Transformers ecosystem.

---

## Task Overview

| **Task**              | **Pipeline Name**       | **Best For**                                                                 |
|-----------------------|-------------------------|------------------------------------------------------------------------------|
| 🧠 **Text Generation** | `text-generation`        | Autocomplete, writing stories, answering questions (if model is trained for it) |
| 🗣️ **Conversational**  | `conversational`         | Chatbots with memory of previous turns (uses `Conversation` object)         |
| 🔍 **Question Answering** | `question-answering`  | Finding answers in a given passage or document (extractive QA)              |
| 🏷️ **Text Classification** | `text-classification` | Assigning labels like sentiment, spam, topic, etc.                          |
| 🧠 **Zero-Shot Classification** | `zero-shot-classification` | Labeling text without task-specific training (e.g. categorize tweets as "business" or "casual") |
| 📑 **Summarization**   | `summarization`          | Summarizing articles, long paragraphs, emails, etc.                         |
| 🌍 **Translation**     | `translation`            | Translating text from one language to another                               |
| 🧬 **Fill-Mask**       | `fill-mask`              | Predicting masked words in a sentence (`"The capital of France is <mask>"`) |
| 🧷 **NER** (Entity Recognition) | `ner`               | Highlighting names, places, companies, etc. in text                         |
| 🧩 **Feature Extraction** | `feature-extraction`    | Converting text into vector embeddings for similarity search, clustering    |
| 🗣️ **Text2Text Generation** | `text2text-generation` | General-purpose input → output tasks (T5, FLAN-T5; used for summarization, QA, etc.) |
| 🎨 **Image Classification** | `image-classification` | Classifying images (e.g., cats vs. dogs) — not text-based                  |
| 🧑‍🎤 **Token Classification** | `token-classification` | Like NER, but general purpose token labeling                                |

## Most Common for LLM Use

| **Use Case**          | **Suggested Task**        | **Notes**                                            |
|------------------------|---------------------------|------------------------------------------------------|
| Chat, completions       | `text-generation`         | Use instruct-tuned models for best results           |
| Fact QA from text       | `question-answering`      | Needs both `question` and `context`                  |
| Categorization          | `text-classification`     | Sentiment, spam, intent, etc.                        |
| Flexible labeling       | `zero-shot-classification`| Works without fine-tuning — very handy               |
| TL;DRs                  | `summarization`           | Works well with long-form input                      |
| Prompt logic chains     | `text2text-generation`    | Models like T5 that do many NLP tasks in one         |
